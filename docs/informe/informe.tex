\section{Introducción}
El presente documento describe el desarrollo de la API REST para la gestión de inventario del Mercado Municipal de Quevedo, utilizando Spring Boot 3, PostgreSQL, Redis y JWT.

\section{Arquitectura}
Se empleó una arquitectura por capas separando controladores, servicios y repositorios \cite{martin2017clean}. La paginación y validación se aplicó en los endpoints.

\section{Evidencias}
Las capturas de funcionamiento se encuentran en la carpeta de evidencias, verificando el funcionamiento del cache-aside \cite{kleppmann2017design} y JWT.
